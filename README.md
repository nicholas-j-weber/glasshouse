# Glasshouse

Glasshouse is an AI context architecture: ACM2 (Auditable Context & Memory
Methodology) — a legible, stateless-per-call approach to managing what an
AI knows — plus an auditable multi-step reasoning agent and a versioned
code-diff lane. The goal is to minimize the system's opacity surface:
shrink where failures can hide, rather than claim to eliminate black-box
behavior outright. Every memory, branch, and step is meant to be logged
and re-runnable in isolation.

This repo is a browser-based demo of that architecture and is currently
under construction.
